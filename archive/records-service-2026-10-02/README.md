# Archived records-service website

This is a source snapshot of the Orbisy grease-interceptor records website before the agency conversion. It preserves the homepage, restaurant and hauler pages, shared components, styles, public metadata, policy pages, tracking definitions, and five portal-concept images.

Source: `eavesa2796/Orbisy-Web-App`, commit `f83593bb7f194dfef87f6e34ddebffa3a29f82d4`.

The source files end in `.txt` so they do not participate in TypeScript compilation, tests, or Next.js routing. This folder is outside `public` and `src/app`, so the archived pages are not served by the agency site.

To revisit the product, create a separate Git branch and copy the desired source files back to their original paths, removing only the final `.txt` extension. Image files under this archive’s `public` folder belong in the project’s `public` folder. The original source commit also remains the reference for restoring the complete prior application.

Restore the source files as a group if you want the entire old public site: the pages depend on their original shared components, form copy, configuration, styles, and metadata. Preserve any subsequent database and administrator changes separately; this snapshot does not change or archive client data.
