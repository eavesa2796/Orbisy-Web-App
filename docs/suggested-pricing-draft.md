# Suggested pricing draft — Anthony’s review

These are proposed starting ranges, not Orbisy’s confirmed rates or market benchmarks. They are separate from the persisted pricing catalog. All standard catalog entries start with unset amounts. No inquiry budget range was used to determine these values.

| Engagement | Proposed draft (USD) | Assumed scope |
| --- | --- | --- |
| Website project | $2,500–$5,000 once | 4–6 pages, supplied images, one form, two design review rounds |
| Google Ads setup | $500–$1,000 once | One local Search account; landing pages and tools separate |
| Google Ads management | $400–$800 monthly | Limited initial campaigns; ad spend paid separately to Google |
| Local SEO setup | $500–$1,000 once | Single location, baseline review and agreed cleanup |
| Ongoing local SEO | $500–$1,000 monthly | Explicit content/profile deliverables; no ranking guarantee |
| Custom development, integrations, automation | $90–$125 hourly or milestone quote | Estimate after discovery; third-party API fees separate |
| Maintenance | $100–$250 monthly | Define included time, platforms, backups, response window; hosting separate |
| Support | $90–$125 hourly | Approved task scope and response expectations |
| Campaign landing page | $600–$1,200 once | One offer, approved content, existing brand, simple inquiry |
| Additional website page | $200–$400 per page | Existing components and approved content |
| Copywriting | $150–$300 per page | Defined page and one revision round |
| Conversion measurement setup | $250–$500 once | Defined events, consent-aware implementation, verification |
| Local service launch package | Individually quoted components | Itemize website, Ads setup, ongoing fees and ad spend |

Before approving a rate, estimate actual hours, overhead, desired margin, included revisions, support obligations, and client acquisition cost. A useful internal check is `estimated delivery hours × target effective hourly rate + direct project costs + scope contingency`. Quote hosting, software subscriptions, and advertising spend separately where applicable. Define what counts as a change request.

Review these ranges, then enter only your approved amounts in the authenticated Pricing catalog. The application does not automatically import this draft.
